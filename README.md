# Anivirudhan Ramesh Portfolio

A recruiter-friendly, interactive portfolio built with Next.js.

## What is included
- Responsive landing page
- Experience timeline with interactive tabs
- Filterable project section
- Skills and certifications
- Resume download
- Contact section
- Dark mode toggle

## Before deploying
Update these placeholder links in `app/page.js`:
- LinkedIn
- GitHub

## Run locally
npm install
npm run dev

## Build
npm run build
npm run start

## Deploy to Vercel
1. Push this folder to GitHub.
2. Import the repository into Vercel.
3. Click Deploy.
